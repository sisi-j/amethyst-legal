## 2. What the Service does

- **Donut Verify** links a Discord account to a DonutSMP Minecraft account,
  once, for every server in the network, and can give a role to verified
  members.
- **Global Schematics** is a free, shared library of Minecraft build files
  (schematics) that members upload, browse, download and rate.
- **Donut Server Trust** collects ratings and reports about DonutSMP trading
  communities so people can check a server before dealing with it.

  submissions and reports.
